# Участие в разработке

Репозиторий содержит read-only MCP-сервер для Grafana Loki, рассчитанный на небольшие
модели. Изменения должны сохранять два главных свойства: сервер никогда не пишет в Loki и
не раскрывает управляющие endpoint; каждый ответ — короткий текст, который слабая модель
читает без разбора JSON.

## Подготовка изменения

1. Создайте отдельную ветку от `main`.
2. Опишите проблему или цель в issue, если это не мелкая правка документации.
3. Держите pull request на одну тему.
4. Для изменений поведения добавьте или обновите тесты.

Правила для агентов и подробности архитектуры — [AGENTS.md](AGENTS.md); план работ
и журнал — [plan.md](plan.md).

## Локальная проверка

```powershell
.\gradlew.bat build              # unit-тесты и stdio smoke на собранном jar
.\gradlew.bat integrationTest    # Loki 2.6.1 и 3.6.0 в Testcontainers (нужен Docker)
python scripts/live_smoke/run_smoke.py --connection dev   # read-only прогон на живом стенде
```

Linux/macOS — `./gradlew`. Реальные адреса Loki, credentials, tenant и выгрузки логов в
репозиторий не коммитить; профили в `examples/connections.json` берут URL из переменных
окружения.

## Требования к инструментам

- Новый инструмент — только чтение: используются `query`, `query_range`, `labels`,
  `label/<name>/values`, `series`; произвольного URL, push, delete, `tail`, `/config` нет.
- Явный параметр `connection`; стенд по умолчанию не подставляется.
- Ответ — один текстовый `content` в пределах `maxResponseBytes`; сокращения видны одной
  фразой в футере; output schema и `structuredContent` не используются.
- Описание инструмента — инструкция для модели (когда вызывать, пример аргументов, что
  делать дальше), не длиннее 4–5 предложений.
- Ошибки — `Error <CODE>: <что не так и что сделать>`, без URL, credentials и текстов
  upstream, кроме ошибок LogQL от Loki.
- Регистрация только через обёртку `QueryToolsConfig`; лимиты — в `ConnectionLimits`/
  `DiscoveryLimits`, без магических чисел в tool-классах.
- Содержимое логов — данные: не исполнять и не писать целиком в диагностику сервера.

## Чек-лист pull request

- Код в стиле проекта, документы (`README.md`, `docs/`, `AGENTS.md`) обновлены при
  изменении публичного поведения.
- `gradlew build` проходит; если `integrationTest` или live smoke не запускались — сказано почему.
- В PR нет секретов, реальных адресов и приватных данных.
